Class LanguageGenerator

java.lang.Object
org.eu.autogex.algorithms.LanguageGenerator
public final class LanguageGenerator extends Object

      public static String generateRandom(DFA dfa, int maxLength)
      Generates a random valid string accepted by dfa whose length does not exceed maxLength.

      The walk is guided by shortest-path distances to accepting states so that cyclic DFAs and dead-end sink states cannot cause infinite loops or failed generations.

      Parameters:
      dfa - the deterministic finite automaton
      maxLength - the maximum allowed length of the generated string (inclusive)
      Returns:
      a randomly generated string accepted by dfa
      Throws:
      NullPointerException - if dfa is null
      IllegalArgumentException - if maxLength < 0 or if dfa accepts no strings of length <= maxLength

    • generateAll

      public static List<String> generateAll(DFA dfa, int maxLength)
      Enumerates all strings accepted by dfa up to maxLength (inclusive) in canonical lexicographical order (ordered by increasing length, then alphabetically).

      Uses a bounded Breadth-First Search (BFS) pruned to co-accessible states so cyclic DFAs are safely traversed without entering infinite loops or exploring dead-end sink cycles.

      Parameters:
      dfa - the deterministic finite automaton
      maxLength - the maximum length of generated strings (inclusive)
      Returns:
      an unmodifiable list of all accepted strings of length <= maxLength
      Throws:
      NullPointerException - if dfa is null
      IllegalArgumentException - if maxLength < 0
