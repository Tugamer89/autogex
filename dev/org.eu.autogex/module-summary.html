Module org.eu.autogex

module org.eu.autogex
The AutoGex module provides a zero-dependency engine for Regular Expression compilation and Finite State Automata theory operations.

It includes immutable models (DFA, NFA, ENFA), formal algorithms (Thompson's construction, Rabin-Scott subset construction, Moore's minimization, set operations, and language generation), execution tracing, and diagram exporters for Graphviz DOT and Mermaid.js.
