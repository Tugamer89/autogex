Class AutoGex

java.lang.Object
org.eu.autogex.AutoGex
public final class AutoGex extends Object
Main facade and metadata provider for the AutoGex library.

This utility class provides high-level convenience methods for common workflows—such as compiling regular expressions into minimal DFAs, converting and minimizing automata, computing formal language set operations, and exporting state diagrams—as well as runtime version metadata.

    • VERSION

      public static final String VERSION
      The current version of the AutoGex library.

      This value is dynamically retrieved from the JAR manifest (Implementation-Version). If the library is running un-packaged (e.g., during tests), it falls back to a default snapshot value.
