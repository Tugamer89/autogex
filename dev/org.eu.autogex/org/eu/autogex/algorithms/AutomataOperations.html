Class AutomataOperations

java.lang.Object
org.eu.autogex.algorithms.AutomataOperations
public final class AutomataOperations extends Object
Utility class providing mathematical set operations on Deterministic Finite Automata (DFAs), demonstrating the closure properties of regular languages under complement, intersection, union, and set difference.

    • complement

      public static DFA complement(DFA dfa)
      Computes the complement (L̅) of the language recognized by the given DFA over its derived transition alphabet.

      If the input DFA has a partial transition function over its alphabet, an explicit sink state is introduced prior to inverting accepting and non-accepting states so that all rejected strings over the alphabet are accepted by the complement.

      Parameters:
      dfa - the input deterministic finite automaton
      Returns:
      a new DFA accepting the complement language
      Throws:
      NullPointerException - if dfa is null
