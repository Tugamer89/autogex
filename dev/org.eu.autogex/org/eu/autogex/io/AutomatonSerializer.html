Class AutomatonSerializer

java.lang.Object
org.eu.autogex.io.AutomatonSerializer
public final class AutomatonSerializer extends Object
Utility class for serializing and deserializing finite state automata (DFA, NFA, and ENFA) using a canonical, deterministic JSON representation with zero external dependencies.

Canonical JSON Schema

Every serialized automaton is represented as a UTF-8 JSON object conforming to RFC 8259 with deterministic ordering across all collections:

  • "type" (string): the concrete automaton model ("DFA", "NFA", or "ENFA").
  • "alphabet" (array of single-character strings): all non-epsilon input symbols appearing in transitions, sorted in natural Unicode code-point order. Empty ([]) when the automaton defines no symbol transitions.
  • "states" (array of strings): all state identifiers in the automaton (including unreachable states), sorted lexicographically.
  • "initialState" (string): the identifier of the starting state.
  • "acceptingStates" (array of strings): all accepting (final) state identifiers, sorted lexicographically.
  • "transitions" (array of objects): all transitions sorted by "from", then "symbol" (natural order, with null placed last), then "to". Each entry contains:
    • "from" (string): source state identifier.
    • "symbol" (single-character string or null): consumed input symbol, or null for silent ε-transitions in an ENFA.
    • "to" (string): target state identifier.

Usage Example

DFA dfa = new Regex("(a|b)*abb").getAutomaton();
String json = AutomatonSerializer.toJson(dfa);

Automaton restored = AutomatonSerializer.fromJson(json);
boolean accepted = restored.accepts("aabb"); // true
