Package org.eu.autogex

package org.eu.autogex
AutoGex root package.

This package serves as the primary namespace for the AutoGex library. It contains the main entry points for regex compilation and automation management. The presence of this file ensures the package is recognized by the Java Module System (JPMS) even when it only contains sub-packages.
